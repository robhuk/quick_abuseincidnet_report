STAFF ABUSE & ASSAULT REPORT PWA — PROTOTYPE

Files:
- index.html: the app
- manifest.webmanifest: install metadata
- sw.js: basic offline caching
- README.txt: these instructions

To install as a PWA:
1. Host the contents of this folder on an HTTPS web server.
2. Open the hosted URL in Safari (iPhone) or Chrome (Android).
3. iPhone: Share > Add to Home Screen.
   Android: browser menu > Install app / Add to Home screen.

Features:
- Minor-incident warning and escalation notice
- Service, location, incident narrative, injury and police/Control fields
- Injury details appear when "Yes" is selected
- Abuse categories include sexual harassment
- Control informed status and Control reference number
- CCTV / body-worn video capture status
- Person outcome, management follow-up and report status fields
- Local draft save/load, copy report text, print / Save PDF
- Basic offline caching after first successful load

Important:
This is a prototype and does not submit reports to Control, police, or management.
Drafts are stored in browser local storage on the device. Do not enter sensitive information
on a shared device. Confirm the fields and workflow with your employer before operational use.
